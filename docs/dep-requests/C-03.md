# C-03 dependency request

No additional third-party dependencies are required.

* `python-docx` is already pinned in `pyproject.toml` and covers `.docx` files.
* Legacy `.doc` and `.rtf` files use a configurable system command (LibreOffice
  / soffice) with no extra Python packages.
* Language detection, HTML stripping and Unicode normalisation are implemented
  with the Python standard library.
