## Summary

`make gate` fails on a clean `contracts-frozen` worktree because
`tests/test_fakes_satisfy_protocols.py` has an import order violation that
ruff reports.

## Reproduction

```bash
git checkout contracts-frozen
make gate
```

## Expected vs actual

Expected: `make gate` passes (it is the Wave-0 gate).

Actual:

```
uv run --group dev ruff check src tests
I001 [*] Import block is un-sorted or un-formatted
 --> tests/test_fakes_satisfy_protocols.py:1:1
```

The `from tests.fakes import ...` block is placed before the
`from ats_scan.protocols import ...` block, but ruff treats `tests.fakes` as a
local import that must come after first-party (`ats_scan`) imports.

## Evidence

`ruff` output is the evidence. The file is unchanged from the Wave-0 commit.

## Routing

`tests/test_fakes_satisfy_protocols.py` is a Wave-0 test that exercises the
`tests/fakes/` module and is therefore owned by the foundation (`W0`).  The
fix is to reorder the imports so `ats_scan.protocols` precedes `tests.fakes`.
