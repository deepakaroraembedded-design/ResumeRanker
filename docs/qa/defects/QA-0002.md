## Summary

`make own` cannot infer the component ID for any `feat/C-NN-*` branch because
`scripts/check-ownership.py` parses only the first dash-separated segment of
the branch suffix. For a branch like `feat/C-01-foo` or `feat/C-QA-qa` it
produces the component ID `C`, which is not in the ownership map.

## Reproduction

```bash
git checkout feat/C-01-ingest
make own
```

or

```bash
make own
```

on the current `feat/C-QA-qa` branch.

## Expected vs actual

Expected: `make own` reports the owning component and checks the changed files
against that component's allowed paths.

Actual:

```
uv run --group dev python scripts/check-ownership.py --base contracts-frozen
Unknown component: C
```

## Evidence

`scripts/check-ownership.py` lines 93–97:

```python
if branch.startswith("feat/"):
    prefix = branch.split("/")[1]
    if prefix.startswith("C-"):
        return prefix.split("-")[0]
```

For `feat/C-QA-qa`, `branch.split("/")[1]` is `C-QA-qa`, and
`"C-QA-qa".split("-")[0]` is `C`, not `C-QA`.

The component ID should be the first two dash-separated parts (`C-NN` or
`C-QA`).

## Routing

`scripts/check-ownership.py` is owned by `W0` per the ownership map. The fix
is to extract the first two dash-separated tokens when the prefix starts with
`C-`.
