# C-QA — Independent verification layer

This directory contains the QA agent assets for ATS-Scan.

- `read-log.md` — oracle blind-derivation log (commits vs. implementation reads).
- `defects/` — QA-NNNN defect records routed to owning components.
- `report-*.md` — gate reports.
- `traceability.md` — requirement-to-test cross-reference (generated by `trace.py`).
- `mutants-*.md` — mutation testing triage reports.
- `metrics.csv` — trend metrics across gates.

See `docs/QA_PLAN.md` for the complete QA charter and gate definitions.
