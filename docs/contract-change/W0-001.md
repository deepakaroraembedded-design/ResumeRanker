# W0-001 — `make bench` target is unusable

## Problem

The `bench` target in `Makefile` invokes:

```make
bench:
	$(UV) pytest tests/benchmark --benchmark-compare-fail=mean:20%
```

`pytest-benchmark` requires `--benchmark-compare` whenever `--benchmark-compare-fail` is used. Without a baseline comparison, the run fails after the benchmark test itself has executed successfully.

## Impact

`make bench` cannot pass, even though the benchmark test (`tests/benchmark/test_pipeline.py`) runs and produces a valid result (~330 µs per pipeline run). This blocks the QG2 integration benchmark check and any automated performance gate.

## Evidence

```text
ERROR: --benchmark-compare-fail requires valid --benchmark-compare.
```

Full output is available in the latest local run of `make bench`.

## Proposed fix

Either:

1. Add `--benchmark-compare` to the `bench` target and commit a baseline in `.benchmarks/`, or
2. Split the target into a baseline recorder (`make bench-baseline`) and a comparison target (`make bench`), where the comparison target passes `--benchmark-compare` and `--benchmark-compare-fail=mean:20%`.
