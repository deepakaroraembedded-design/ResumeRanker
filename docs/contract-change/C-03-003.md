# Contract Change Request — C-03-003

## Component

C-03 (Office / plain-text / HTML extraction)

## Frozen contract that is wrong

`Makefile` and `scripts/check-ownership.py` — the `make own` target cannot
infer the component ID for branches with more than one dash after the prefix.

## Problem

The `feat/C-03-extract-office` branch follows the naming convention used by the
Implementation Plan (e.g. `feat/C-15-cli`, `feat/C-QA-qa`).  The ownership check
script infers the component with:

```python
prefix = branch.split("/")[1]  # "C-03-extract-office"
if prefix.startswith("C-"):
    return prefix.split("-")[0]  # returns "C"
```

Because the branch name contains multiple dashes, the inferred component becomes
``C`` instead of ``C-03``, and `make own` fails with:

```
Unknown component: C
make: *** [Makefile:26: own] Error 1
```

## What is needed

In `scripts/check-ownership.py`, change the inference to consume the first two
dash-separated parts:

```python
if prefix.startswith("C-"):
    parts = prefix.split("-")
    return "-".join(parts[:2])  # "C-03" for "C-03-extract-office"
```

And update `Makefile` `own` target to pass the inferred component explicitly so
agents do not need to remember the workaround:

```make
own:
	$(UV) python scripts/check-ownership.py --base contracts-frozen --component $(COMPONENT)
```

with a default `COMPONENT ?= C-03` (or derive it from the branch) in `Makefile`,
or keep it as a required parameter.

## Impact until the change is made

C-03 runs the ownership check manually:

```bash
uv run --group dev python scripts/check-ownership.py --base contracts-frozen --component C-03
```

which reports ``OK: all changes in C-03 owned paths.``

`C-03-003`
