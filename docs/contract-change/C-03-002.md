# Contract Change Request — C-03-002

## Component

C-03 (Office / plain-text / HTML extraction)

## Frozen contract that is incomplete

`src/ats_scan/models/run.py` — `RunContext.config` only exposes
``IngestConfig``, but extraction stages need extraction-section configuration.

## Problem

The TRD §8 and the C-03 Definition of Done require:

* A **configured set of accepted languages** (FR-209, default ``["en"]``).
* A **configurable converter timeout** (FR-208, default 60 s).
* A configurable or discoverable **headless office converter command** (FR-208).

The full ``RootConfig`` already defines ``extraction: dict[str, object]`` with
those keys (TRD Appendix A / IMPLEMENTATION PLAN §3.5), but ``RunContext`` only
stores ``IngestConfig``:

```python
class RunContext(BaseModel):
    config: IngestConfig | None = None
```

Because ``IngestConfig`` does not contain ``languages``,
``converter_timeout_s``, or ``office_converter_cmd``, C-03 extractors cannot read
those values without a frozen-file change.

## What is needed

One of the following (the first is preferred because it mirrors the TRD):

### Option A: store the full RootConfig in RunContext

Change ``RunContext.config`` to the full configuration object:

```python
from ats_scan.models.config import RootConfig

class RunContext(BaseModel):
    config: RootConfig | None = None
```

This lets every stage access its own section (``ctx.config.extraction``,
``ctx.config.llm``, etc.) without inventing per-stage config types.

### Option B: add extraction keys to IngestConfig

Add to ``IngestConfig``:

```python
class IngestConfig(BaseModel):
    ...
    converter_timeout_s: int = 60
    languages: tuple[str, ...] = ("en",)
    office_converter_cmd: str | None = None
```

This is narrower but couples extraction config to the ingest stage.

## Impact until the change is made

C-03 uses these environment-variable fallbacks:

* ``ATS_SCAN_LANGUAGES`` (comma-separated) for FR-209.
* ``ATS_SCAN_CONVERTER_TIMEOUT_S`` for FR-208 timeout.
* ``ATS_SCAN_OFFICE_CONVERTER_CMD`` for FR-208 converter command injection.

All default to the TRD-specified values.  Once the contract is amended, the
environment-variable reads will be replaced by ``ctx.config.extraction`` reads.
