# Contract change request C-08-003

**Component:** C-08 (resume structuring)  
**Requested by:** C-08 builder agent  
**Date:** 2026-08-29  
**Status:** Blocking — `make own` fails on the frozen base

## What is wrong

`scripts/check-ownership.py::infer_component()` extracts the wrong component ID
for branches named `feat/C-NN-name`.

Current code:

```python
def infer_component(branch: str) -> str | None:
    if branch == "main" or branch == "master":
        return "W0"
    if branch.startswith("feat/"):
        prefix = branch.split("/")[1]
        if prefix.startswith("C-"):
            return prefix.split("-")[0]
    return None
```

For branch `feat/C-08-structure`, `prefix = "C-08-structure"` and
`prefix.split("-")[0]` returns `"C"`, not `"C-08"`. The `make own` target then
runs `python scripts/check-ownership.py --base contracts-frozen`, which reports
`Unknown component: C` and exits with code 1.

## What is needed

Parse the component prefix as the first two dash-separated parts (`C-08`, not
`C`). For example:

```python
def infer_component(branch: str) -> str | None:
    if branch in ("main", "master"):
        return "W0"
    if branch.startswith("feat/"):
        prefix = branch.split("/")[1]
        if prefix.startswith("C-"):
            return "C-" + prefix.split("-")[1]
    return None
```

or use a regex such as `^C-\d+` to capture the component ID.

Additionally, the contract-change protocol (docs/IMPLEMENTATION_PLAN.md §7.6)
requires component agents to write files under `docs/contract-change/` using the
pattern `<ID>-NNN.md`. The current ownership map assigns that directory to W0,
so once `infer_component` is fixed, `check-ownership.py` will flag the very
contract-change files that the process mandates. The script (or the ownership
map) should allow a component to write `docs/contract-change/<ID>-*.md` files.
For example, C-08 should be permitted to create `docs/contract-change/C-08-*.md`.

## What the C-08 agent will do meanwhile

`make own` cannot be used as a green signal. For local verification the agent
has run the ownership check manually with `--component C-08`, but the
Makefile-gated target is broken. C-08 will resume normal use of `make own`
after the amendment and rebase.
