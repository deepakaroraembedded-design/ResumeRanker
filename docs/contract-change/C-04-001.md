# Contract Change Request C-04-001

## Problem

`tests/test_fakes_satisfy_protocols.py` fails `ruff check` with import-order error
`I001`:

```text
I001 [*] Import block is un-sorted or un-formatted
```

The first-party imports are sorted as `tests.fakes` before `ats_scan.protocols`,
but `ats_scan` must come before `tests` alphabetically.

## Impact

`make gate` is red on a clean `contracts-frozen` checkout because `make lint`
flags this file. Component agents cannot resolve this without editing a file
outside their owned paths.

## Proposed Change

Re-order the imports so `ats_scan.protocols` precedes `tests.fakes`, or add the
file to the W0 ownership map so it can be maintained by the foundation agent.

## Affected Component

W0 foundation.
