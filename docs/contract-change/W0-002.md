# W0-002 — Add `mutmut` to dev dependencies

## Problem

`mutmut` is required for the QG1/QG2 mutation gate (QA_PLAN §4). It is not pinned in the Wave-0 lockfile, so the QA runner `scripts/qa/mutate.py` records a soft dependency request instead of executing the gate.

The user has installed `mutmut` on the host, but the host installation is for Python 3.10 and cannot run against the Python 3.12 project environment. The project venv (managed by `uv`) does not contain `mutmut`, and `uv run` will not include it unless it is declared in `pyproject.toml` and `uv.lock`.

## Impact

- `make qa-mutate` and the mutation entry point in `make qa-gate` cannot execute.
- The QG1/QG2 mutation score threshold for `scoring/**` (≥ 90 %) cannot be verified.
- `docs/dep-requests/C-QA.md` remains open.

## Proposed fix

Add `mutmut` to the dev dependency group in `pyproject.toml` and regenerate `uv.lock` so that `uv run --group dev mutmut` works within the project venv.

## Decision

Approved by project lead. Implementation owner: W0.

## Owner

W0 (`pyproject.toml` and `uv.lock` are Wave-0 frozen files).
