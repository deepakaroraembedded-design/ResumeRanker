# Contract-change request C-01-002

## Component
C-01 (ingest)

## W0 file that appears wrong
`tests/test_fakes_satisfy_protocols.py` (W0 shared test infrastructure)

## Problem
`ruff check` reports I001 on this file:

```
Import block is un-sorted or un-formatted
```

The import order places the local `tests.fakes` import before the first-party
`resume_ranker.protocols` import. Ruff expects the first-party import block before
the local-project block.

## Impact
`make lint` and therefore `make gate` fail for any branch that runs the
project-wide lint. C-01 cannot fix this file because it is outside its owned
paths.

## Suggested fix
Reorder the imports so that `from resume_ranker.protocols import ...` appears
before `from tests.fakes import ...`.

## Does this block C-01 work?
Yes, it blocks the `make lint` / `make gate` target for the whole
repository.
