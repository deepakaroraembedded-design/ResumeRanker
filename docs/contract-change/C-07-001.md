# Contract Change Request C-07-001

## File
`scripts/check-ownership.py`

## Problem
`infer_component()` cannot parse component IDs with a slug that contains a dash.
For branch `feat/C-07-report` it returns `C` instead of `C-07`, so `make own` fails
with:

```
Unknown component: C
```

## Evidence
```python
prefix = "C-07-report"
prefix.split("-")[0]  # -> "C"
```

## What is needed
Parse the component ID as the first two dash-separated segments, e.g.
`"-".join(prefix.split("-")[:2])` or use a regex `^C-\d+`.

## What C-07 will do meanwhile
Run `check-ownership.py` with `--component C-07` to verify ownership locally and
record the official `make own` failure as a pre-existing W0 defect in the final
report.
