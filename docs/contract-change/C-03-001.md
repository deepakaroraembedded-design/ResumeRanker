# Contract Change Request — C-03-001

## Component

C-03 (Office / plain-text / HTML extraction)

## Frozen contract that is missing

`src/resume_ranker/models/source.py` — the shared Unicode text-normalisation helper
referenced by the C-03 Definition of Done.

## Problem

The Implementation Plan §4 (C-03) requires:

> Same Unicode normalisation contract as C-02 — **import the shared helper from
> `models/source.py`, do not reimplement**.

`models/source.py` currently defines `SourceDocument`, `ExtractionMetadata`,
`TextBlock`, and `ExtractedText`, but does **not** expose a shared text
normalisation helper.  Because the file is frozen under the Wave-0 contract,
C-03 cannot add the helper locally.

## What is needed

Add a public helper to `src/resume_ranker/models/source.py`:

```python
def normalise_text(text: str) -> str:
    """Return the C-02/C-03 shared Unicode normalisation of *text*.

    Implements FR-210: NFKC normalisation, common ligature repair, and removal
    of zero-width and bidirectional control characters.
    """
```

with the following behaviour (the same contract C-02 must satisfy):

1. Decode the input string as-is (callers are responsible for file decoding).
2. Apply `unicodedata.normalize("NFKC", text)`.
3. Remove zero-width characters:
   U+200B, U+200C, U+200D, U+FEFF (BOM / zero-width NBSP).
4. Remove bidirectional control characters:
   U+202A–U+202E, U+2066–U+2069.
5. Return the cleaned string.

## Impact until the change is made

C-03 will implement a component-private stop-gap helper that produces the same
output, so FR-210 is still met.  Once `models/source.py` exposes the helper, the
C-03 stop-gap will be replaced by an import.

The C-03 DoD checkbox "import the shared helper from `models/source.py`" is
**blocked** until this contract change is merged and the tag `contracts-frozen`
is moved.

## Suggested contract amendment ID

`C-03-001`
