# Contract change request C-08-001

**Component:** C-08 (resume structuring)  
**Requested by:** C-08 builder agent  
**Date:** 2026-08-29  
**Status:** Blocking — cannot proceed without amendment

## What is wrong

`src/ats_scan/models/run.py::RunContext` does not expose the run date. The
frozen C-08 Definition of Done (docs/IMPLEMENTATION_PLAN.md §4, C-08) requires:

> Date parsing for all formats in FR-303, `DatePrecision` recorded,
> "Present"/"Current"/"Till date" → `ctx.now`

TRD FR-303 also requires resolving "Present" / "Current" / "Till date" to the run
date. The only place the run date is currently defined is
`ScoringContext.now`, which is available to scoring dimensions but **not** to the
`Structurer` protocol, whose `structure(text, ctx: RunContext)` signature only
receives a `RunContext`.

Because `RunContext` is frozen, the structurer cannot access the run date,
cannot resolve open-ended dates, and cannot compute the calendar-union timeline
or `parse_completeness` deterministically without calling `date.today()` or
`import time`, both of which are forbidden by the project hard rules.

## What is needed

Add an ISO-8601 date field to `RunContext` so that the pipeline can inject the
same `now` value used for `ScoringContext`:

```python
class RunContext(BaseModel):
    run_id: str
    config: IngestConfig | None = None
    output_dir: Path | None = None
    cache_dir: Path | None = None
    diagnostics: tuple[Diagnostic, ...] = ()
    now: str | None = None          # ISO-8601 date; used by structuring
```

A default of `None` keeps the model backward-compatible, but the pipeline must
populate it before calling a structurer. If `now` is `None`, the C-08
implementation will treat open-ended dates as `DatePrecision.PRESENT` with
`value=None` and emit a diagnostic rather than guessing the current date.

## What the C-08 agent will do meanwhile

Stop implementation on this branch. No structuring code that touches dates or
timeline will be written until the contract amendment lands and the branch is
rebased on the moved `contracts-frozen` tag. The heuristic and LLM structurer
designs are otherwise ready to implement once the run date is available.
