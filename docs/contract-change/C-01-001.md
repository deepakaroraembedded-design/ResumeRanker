# Contract-change request C-01-001

## Component
C-01 (ingest)

## Frozen file that appears wrong
`Makefile` (owned by W0)

## Problem
The `own` target runs:

```make
own:
	$(UV) python scripts/check-ownership.py --base contracts-frozen
```

`scripts/check-ownership.py` infers the component ID from the branch name with:

```python
prefix = branch.split("/")[1]
if prefix.startswith("C-"):
    return prefix.split("-")[0]
```

For branch `feat/C-01-ingest`, `prefix` is `C-01-ingest` and
`prefix.split("-")[0]` returns `C`. The script then reports
`Unknown component: C` and `make own` fails.

## Impact
`make own` cannot be run as-is on component branches whose IDs contain a
hyphen (e.g., C-01, C-02, ..., C-15). C-01 worked around it by invoking the
script directly with `--component C-01`, but the Makefile target is broken.

## Suggested fix
Change the component inference logic to treat the whole `C-NN` prefix as the
component ID, e.g.:

```python
if prefix.startswith("C-"):
    return "-".join(prefix.split("-")[:2])
```

Or update the `Makefile` to pass `--component` explicitly.

## Does this block C-01 work?
Yes, the `make own` gate target is non-functional for C-01 without a
workaround.
