# Contract Change Request C-04-002

## Problem

`scripts/check-ownership.py` cannot infer the component ID for branch names like
`feat/C-04-ontology`.

Current code:

```python
if branch.startswith("feat/"):
    prefix = branch.split("/")[1]
    if prefix.startswith("C-"):
        return prefix.split("-")[0]
```

For `feat/C-04-ontology` this returns `"C"` instead of `"C-04"`, so
`make own` fails with:

```text
Unknown component: C
```

## Impact

Component agents running the documented `make own` target receive a false
ownership violation for any branch whose component ID contains a hyphen and a
suffix.

## Proposed Change

Parse the component ID as the first two dash-separated parts of the branch
suffix, e.g.:

```python
return "-".join(prefix.split("-")[:2])
```

or update the ownership map to explicitly associate the branch name with the
component.

## Affected Component

W0 foundation.
