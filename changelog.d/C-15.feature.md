C-15: CLI, configuration resolver and pipeline orchestrator

- Implemented `resume_ranker.config.ConfigResolver` with flag > env (`ATS_*` prefix,
  `__` nesting) > file > default precedence and a redacted config hash.
- Implemented `resume_ranker.pipeline.Pipeline` with dependency injection for all
  frozen protocols, fault-isolated per-document execution, and wiring for the
  seven CLI commands.
- Implemented `resume_ranker.cli.main` with Typer commands: `run`, `parse`,
  `compile-jd`, `explain`, `validate-config`, `calibrate`, `audit`, and the
  TRD §7.3 exit codes.
- Added integration tests for config precedence and pipeline wiring, e2e CLI
  tests using fakes, and a benchmark for the pipeline orchestration.
