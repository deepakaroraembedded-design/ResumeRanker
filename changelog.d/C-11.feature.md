Implemented the C-11 semantic-relevance dimension (S3) and the embeddings client.

- Added a local sentence-transformer embedding client with SHA-256 keyed cache,
  configurable batch size, and an optional hosted-client placeholder.
- Implemented `S3Semantic` with JD/resume chunking, asymmetric max-similarity,
  pool calibration (p10/p90 for pools of 30+, fixed 0.25/0.70 anchors below),
  and the 0.6 embedding / 0.4 LLM-rubric blend from TRD §5.3.3.
- Exposed `S3Semantic.prepare()` for two-pass pool calibration and returned the
  rubric sample spread in `SubScore.detail["rubric_stdev"]` for C-13 confidence.
- Added unit tests under `tests/unit/scoring_semantic/` for the S3 formula,
  calibration, determinism, and the embedding client.
