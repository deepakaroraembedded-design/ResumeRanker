C-04: Ontology & normalisation

- Implemented `SkillOntology` (`OntologyIndex`) with the FR-501 match cascade
  (exact, alias, case/punctuation-insensitive, fuzzy, embedding) and parent/child
  skill relations backed by `data/ontology/2026.07/skills.json`.
- Implemented `TitleTaxonomy` with family + seniority normalisation, inflated-title
  handling, and the S5 similarity scale; data lives in `data/titles/2026.07/titles.json`.
- Added `EmployerNormalizer` for legal-suffix stripping and alias mapping using
  `data/ontology/2026.07/employers.json`.
- Seeded the ontology with 1,581 canonical skills across the pilot role families.
- Added unit and property tests for matching, titles, employers, loaders, and warm-cache
  lookup throughput.
