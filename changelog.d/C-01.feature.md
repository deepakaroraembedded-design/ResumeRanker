# C-01 feature newsfragment

Implemented the ingest & triage stage.

- `build_manifest(root, cfg)` walks the input directory recursively, applies
  include/exclude globs, detects media types from magic bytes, computes
  content SHA-256 hashes, detects exact and SimHash near-duplicates, and
  enforces size and page-count guards without raising.
- `Manifest` and `DuplicateCluster` models capture accepted documents,
  duplicate clusters, and skip diagnostics.
- `cluster_by_identity(resumes)` is exposed separately for the pipeline stage
  to de-duplicate by normalised contact identity after structuring.
- Added unit and property tests covering globs, symlinks, magic-byte detection,
  hash/SimHash clustering, representative selection, oversize guards, zip-bomb
  detection, and stable ordering.
