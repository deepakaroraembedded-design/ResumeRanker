# C-06 feature newsfragment

Implement the three integrity detectors required by TRD §3.11 / FR-1101–1104:

- `HiddenTextDetector` detects colour near the page background, font size below
  the configured minimum, render mode 3, and text outside the media box, and
  raises `HIDDEN_TEXT` when the hidden-token share exceeds the configured
  threshold.
- `KeywordStuffingDetector` detects skill repetition without context,
  skills-section token share above the configured maximum, and
  claimed-but-unnarrated skills, returning `KEYWORD_STUFFING`.
- `InjectionDetector` detects instruction-like content directed at a language
  model and returns exact spans for quarantine as `INJECTION_ATTEMPT`.

Unit tests cover each detector boundary; adversarial tests run over the Wave 0
fixture corpus and assert the TRD §13.3 recall targets and zero false positives
on clean resumes.
