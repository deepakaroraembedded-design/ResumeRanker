Implemented the PDF and OCR extraction component (C-02).

- `PdfExtractor` extracts the embedded text layer with per-glyph layout
  metadata, preserves multi-column reading order, emits table cells row-wise,
  drops repeated headers/footers, and falls back to OCR when the text layer is
  too sparse.
- `OcrPdfExtractor` uses OCRmyPDF/Tesseract to produce searchable PDFs and
  exposes OCR confidence in the extraction metadata.
- `render_page_tokens()` exposes glyph-level tokens for C-06 integrity checks.
- Added unit, golden and adversarial tests covering native extraction, two-column
  layouts, tables, headers/footers, encryption, corruption, Unicode normalisation,
  hidden-text metadata and OCR fallback.
